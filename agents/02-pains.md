# Агент 2 — Боли аудитории

## Роль

Собрать формулировки болей МСБ и предпринимателей по теме AI/автоматизации из открытых источников.

## Вход

- Схема: `data/schemas/pain-record.json`
- Опционально: топ-запросы из `data/raw/demand-*.json` для уточнения поисковых запросов

## Инструмент

Firecrawl CLI:

```bash
firecrawl search "QUERY" --scrape -o data/raw/pains-SOURCE-YYYY-MM-DD.json --json
```

## Поисковые запросы (обязательный минимум)

| # | Запрос |
|---|--------|
| 1 | `"внедрение ии" site:vc.ru` |
| 2 | `"автоматизация бизнеса" проблемы` |
| 3 | `"ии для бизнеса" site:habr.com` |
| 4 | `"автоматизация" предприниматель site:vc.ru` |
| 5 | `"chatgpt для бизнеса" опыт` |
| 6 | `"интернет магазин" автоматизация проблемы` |
| 7 | `"n8n" внедрение site:habr.com` |

## Алгоритм

1. Выполнить поисковые запросы через Firecrawl (с `--scrape` для полного текста)
2. Из каждого результата извлечь 1–3 цитаты боли **словами автора**
3. Классифицировать `audience_segment`: smb / ecommerce / enterprise / freelancer
4. Привязать к `topic_cluster` (A–J) если возможно
5. Сохранить в `data/raw/pains-YYYY-MM-DD.json`

## Формат выхода

```json
{
  "agent": "02-pains",
  "collected_at": "2026-08-06T20:00:00Z",
  "records": [
    {
      "source_url": "https://vc.ru/...",
      "title": "...",
      "pain_quote": "Потратили 200к на внедрение, а сотрудники всё равно делают вручную",
      "audience_segment": "smb",
      "topic_cluster": "J",
      "platform": "vc.ru",
      "collected_at": "2026-08-06T20:05:00Z"
    }
  ]
}
```

## Критерии качества pain_quote

- Конкретная проблема, не общие слова
- Желательно с контекстом (деньги, время, люди, инструменты)
- На русском языке
- Без дубликатов (проверять по URL и смыслу)

## Лимиты

- Не более 7 поисковых запросов за прогон
- Целевой объём: 30–50 уникальных pain_quote

## Dry-run

Один запрос: `"внедрение ии" site:vc.ru` → минимум 3 pain_quote.
