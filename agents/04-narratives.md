# Агент 4 — Нарративы и новости

## Роль

Отслеживать текущие нарративы, тренды и новости по AI/автоматизации для бизнеса в РФ.

## Вход

- Темы из кластеров demand (опционально)

## Инструмент

Firecrawl CLI — поиск новостей:

```bash
firecrawl search "QUERY" --sources news --tbs qdr:m -o data/raw/narratives-QUERY-YYYY-MM-DD.json --json
```

`--tbs qdr:m` — новости за последний месяц.

## Поисковые запросы

| # | Запрос |
|---|--------|
| 1 | `ai бизнес россия` |
| 2 | `автоматизация мсб` |
| 3 | `искусственный интеллект компании россия` |
| 4 | `geo seo оптимизация` |
| 5 | `ии интернет магазин` |
| 6 | `n8n автоматизация` |
| 7 | `внедрение ии малый бизнес` |

## Алгоритм

1. Выполнить 7 news-поисков
2. Для каждого результата извлечь:
   - `narrative` — ключевой нарратив (1 предложение)
   - `source` — URL
   - `date` — дата публикации
   - `relevance_to_positioning` — high / medium / low (близость к e-commerce + AI + МСБ)
3. Дедуплицировать похожие нарративы
4. Сохранить в `data/raw/narratives-YYYY-MM-DD.json`

## Формат выхода

```json
{
  "agent": "04-narratives",
  "collected_at": "2026-08-06T20:00:00Z",
  "records": [
    {
      "narrative": "Компании массово внедряют AI-агентов для клиентской поддержки",
      "source": "https://...",
      "date": "2026-08-01",
      "relevance_to_positioning": "high",
      "topic": "ai_agents"
    }
  ],
  "summary": {
    "top_narratives": [
      "AI-агенты вместо отдела поддержки",
      "GEO как новый SEO",
      "Автоматизация без программистов (no-code)"
    ]
  }
}
```

## Типичные нарративы для отслеживания

- AI заменит / не заменит сотрудников
- Импортозамещение софта (1С, Bitrix, российские CRM)
- GEO / генеративная оптимизация
- AI-агенты и автономные системы
- Уход с маркетплейсов на свой сайт
- No-code / n8n / Make как стандарт МСБ

## Лимиты

- 7 news-поисков за прогон
- Без `--scrape` (достаточно сниппетов из news)

## Dry-run

Один запрос: `ai бизнес россия --sources news --tbs qdr:m`
