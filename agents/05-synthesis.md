# Агент 5 — Синтез

## Роль

Объединить данные агентов 1–4 в actionable-рекомендации: векторы услуг, gap-ниши, позиционирование, контент-план.

## Вход

- `data/raw/demand-*.json` — спрос
- `data/raw/pains-*.json` — боли
- `data/raw/competitors-*.json` — конкуренты
- `data/raw/narratives-*.json` — нарративы
- Схема: `data/schemas/synthesis-output.json`

## Фильтр «ваш треугольник»

Каждая рекомендация проходит через три критерия:

```
AI/автоматизация  +  E-commerce/измеримый результат  +  Кейс (магазин аккумуляторов)
```

| Рекомендация | Условие |
|--------------|---------|
| **sell** | fit_score ≥ 4, commercial_intent high/medium, content_gap у конкурентов |
| **content** | fit_score 3–4, высокий охват, слабая конкуренция в объяснении |
| **skip** | fit_score ≤ 2 или переполненная commodity-ниша |

## Алгоритм

1. Загрузить все `data/raw/*.json` (последние по дате)
2. **Векторы услуг** (5–7 шт.):
   - Название вектора
   - Доказательство спроса (из demand)
   - Боль (из pains)
   - Конкурентная ситуация (из competitors)
   - Рекомендация: sell / content / skip
3. **Gap-ниши** (3–5 шт.):
   - Спрос растёт (trend up или высокая частотность)
   - Конкуренты объясняют шаблонно
   - Ваш fit_score ≥ 4
4. **Позиционирование**:
   - Одна фраза (one-liner)
   - 3 услуги-входа (аудит, пилот, сопровождение)
5. **Контент-план** — 20 тем для YouTube/Telegram:
   - 7 awareness (охват)
   - 7 trust (кейсы, разборы)
   - 6 lead (CTA на аудит/консультацию)

## Выходные файлы

Сохранить в `data/reports/`:

| Файл | Содержание |
|------|------------|
| `vectors.md` | 5–7 векторов услуг с обоснованием |
| `gaps.md` | Gap-ниши |
| `positioning.md` | One-liner + 3 услуги + ЦА |
| `content-plan.md` | 20 тем с каналом и воронкой |
| `synthesis-YYYY-MM-DD.json` | Полный JSON по схеме |
